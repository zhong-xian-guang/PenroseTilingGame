# 08: 心流模式

**What to build:** 玩家可以隨時在自由模式與心流模式之間切換，目前這局不受影響。心流模式下，系統標出一個推薦位置：優先選在上一片附近（預設 2 個長度單位內）、候選放置最少的凹處，附近都沒有時，才挑離上一片最近的凹處。玩家選了拼塊之後，預放直接吸附到推薦位置，玩家只需要挑方向。鏡頭只在推薦點快要離開可視範圍時才平滑地平移。棋譜記下每一步用的模式；分數不區分模式。

**Blocked by:** 05 成長圓

**Status:** resolved

- [x] 引擎提供心流推薦位置的查詢：附近有凹處時，挑其中候選放置最少的；附近沒有時，挑最近的凹處（有測試）
- [x] 推薦位置一定在成長圓內（有測試）
- [x] 切換模式不改變局面，並記錄在棋譜中（有測試）
- [x] 心流模式下，選了拼塊後預放吸附到推薦位置，滾輪或點擊只在合法方向間循環
- [x] 鏡頭只在推薦點快要離開可視範圍時平滑地平移；附近半徑與平移門檻都是集中定義的可調常數
- [x] 推薦點畫在盤面上

## Comments

- 刻意偏離（程式碼審查後記錄）：沒有任何凹處（角度合計超過半圈的點）時，推薦點退而求其次，從**所有**開放的邊界點（圓內、有候選放置接在上面的點）中挑選，而不是不給推薦。理由：剛開局或鋪砌很圓時可能完全沒有凹處，不給推薦的話心流模式就停住了。
- 刻意偏離（程式碼審查後記錄）：心流模式下選了拼塊後，**預覽**吸附到推薦位置（滾輪／點擊在合法方向間循環），再點一下預覽（或從托盤拖曳放開）才真正放下成為預放，而不是一選拼塊就直接建立預放。理由：放下新的一片會自動確認前一片預放；若一選拼塊就放下，前一片就在玩家還沒看清方向時被確認了，違反「預放在放下一片之前都能修改」。
