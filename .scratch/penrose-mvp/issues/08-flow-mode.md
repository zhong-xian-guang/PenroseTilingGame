# 08: 心流模式

**What to build:** 玩家可以隨時在自由模式與心流模式之間切換，目前這局不受影響。心流模式下，系統標出一個推薦位置：優先選在上一片附近（預設 2 個長度單位內）、候選放置最少的凹處，附近都沒有時，才挑離上一片最近的凹處。玩家選了拼塊之後，預放直接吸附到推薦位置，玩家只需要挑方向。鏡頭只在推薦點快要離開可視範圍時才平滑地平移。棋譜記下每一步用的模式；分數不區分模式。

**Blocked by:** 05 成長圓

**Status:** ready-for-agent

- [ ] 引擎提供心流推薦位置的查詢：附近有凹處時，挑其中候選放置最少的；附近沒有時，挑最近的凹處（有測試）
- [ ] 推薦位置一定在成長圓內（有測試）
- [ ] 切換模式不改變局面，並記錄在棋譜中（有測試）
- [ ] 心流模式下，選了拼塊後預放吸附到推薦位置，滾輪或點擊只在合法方向間循環
- [ ] 鏡頭只在推薦點快要離開可視範圍時平滑地平移；附近半徑與平移門檻都是集中定義的可調常數
- [ ] 推薦點畫在盤面上
