# 06: 觸控操作

**What to build:** 在手機上可以完全單指操作：從托盤拖出 kite 或 dart，預覽畫在手指上方，避免被手指擋住；放開手指時吸附到最近的候選放置，成為預放；之後每點一下預放，就切換到下一個合法方向，把它拖回托盤就是移除。在空白盤面上單指拖曳是平移，雙指是縮放。

**Blocked by:** 03 預放：換方向、移除、自動確認

**Status:** resolved

- [x] 單指從托盤拖出拼塊時，預覽顯示在手指上方，並吸附到最近的候選放置
- [x] 放開手指後成為預放；附近沒有候選放置時則不放
- [x] 點擊預放會循環切換它的合法方向
- [x] 把預放拖回托盤會移除它
- [x] 在空白盤面上單指拖曳是平移，雙指是縮放，都不會誤觸放置
- [ ] 在實機（iOS Safari 與 Android Chrome）上手動驗證過

**Notes:** 前五項以 headless Edge 的 CDP 觸控模擬（390×844、mobile）驗證過：拖出、吸附、放下、點擊換向、拖回托盤移除、平移、雙指縮放、遠處放開與拖回托盤都不放置。實機驗證尚未做，需要人手動測試。觸控時下方提示文字仍是滑鼠操作說明（留給 13 i18n 一起處理，避免衝突）。
