# 04: 可見死局與遊戲結束

**What to build:** 當可放置範圍內的某個邊界凹角或凹洞，對每種拼塊的每個方向試放後都不合法時，就是可見死局。如果死局是預放造成的，凹洞立刻標紅，但遊戲不結束，玩家可以修正；如果玩家不修正、直接放下下一片，遊戲在確認時結束，結算不計那片新的拼塊。結束時跳出最簡版結算窗，顯示面積（以平方長度單位計）和片數，並提供開新局。

**Blocked by:** 03 預放：換方向、移除、自動確認

**Status:** ready-for-agent

- [ ] 引擎能回報可見死局的位置，並區分「預放造成、尚未確認」和「已確認、遊戲結束」（有測試）
- [ ] 預放造成死局時，凹洞標紅，遊戲仍在進行；改方向或移除後，標紅消失（有測試）
- [ ] 判定時序：放下新的一片時，先確認前一片預放，再檢查已確認鋪砌；有死局就結束，而且分數不計新的那一片（有測試）
- [ ] 面積分數等於已確認鋪砌各拼塊面積的總和，kite 與 dart 的面積比為 φ（有測試）
- [ ] 遊戲結束後，引擎拒絕所有放置指令
- [ ] 性質測試：以多個隨機種子反覆「隨機挑一個候選放置放下」直到死局，過程中始終不重疊、相鄰邊都符合匹配規則、每個內部頂點都屬於 7 種頂點組態之一
- [ ] 最簡版結算窗：面積、片數、開新局
