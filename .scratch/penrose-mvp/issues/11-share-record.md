# 11: 分享棋譜

**What to build:** 玩家可以把一局的棋譜分享出去：把棋譜壓縮後放進網址 fragment，做成分享連結；棋譜太長、連結放不下時，改成匯出檔案。收到的人開啟連結或匯入檔案後，就能看到該局的完整重播與分析，而且不會影響自己正在進行的局。

**Blocked by:** 07 棋譜與自動存檔續玩, 09 完整結算窗與分析頁

**Status:** resolved

- [x] 棋譜的網址文字形式編碼後再解碼，重播結果與原局完全相同（有測試）
- [x] 超過連結長度上限時，改為提供檔案匯出
- [x] 開啟分享連結或匯入檔案後，進入該局的重播與分析頁
- [x] 觀看別人的棋譜不會覆蓋自己進行中的局或個人最佳
- [x] 格式版本不相容的棋譜會顯示清楚的錯誤訊息
