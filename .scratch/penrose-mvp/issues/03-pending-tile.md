# 03: 預放：換方向、移除、自動確認

**What to build:** 最新放下的一片是預放。滑鼠移到預放上時，滾輪可以在它的合法方向之間循環，按右鍵就能移除它；放下下一片時，前一片自動確認，沒有確認按鈕。已確認鋪砌永遠不能再更動。畫面上看得出哪一片是預放。

**Blocked by:** 01 專案骨架與第一片拼塊

**Status:** resolved

- [x] 放下拼塊後，它成為預放；引擎的查詢會把已確認鋪砌和預放分開回傳
- [x] 預放換方向時，只在合法方向之間循環（有測試）
- [x] 移除預放後，局面回到放下前的樣子（有測試）
- [x] 放下下一片會確認前一片，而已確認的拼塊無法再被換方向或移除（有測試）
- [x] 滑鼠：在預放上用滾輪換方向、按右鍵移除
- [x] 預放在畫面上有明顯的視覺區別
