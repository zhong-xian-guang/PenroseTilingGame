# 07: 棋譜與自動存檔續玩

**What to build:** 每一步（放下、換方向、移除）都自動寫進本機，關掉 App 或重新整理後，會直接回到原本的局面，包括預放。沒有手動存檔或讀檔。底層是一份帶有格式版本號的棋譜：內容包括拼塊組 id、開局圖形（或能重現它的種子與參數）、每一步的拼塊種類、所接位置、方向，以及預放的修改與移除。每一步附加寫入 IndexedDB，續玩時以引擎重播棋譜還原。本機也保留最近幾局的棋譜。

**Blocked by:** 02 隨機開局圖形, 03 預放：換方向、移除、自動確認

**Status:** resolved

- [x] 引擎提供棋譜查詢，以及「由棋譜重播出局面」的指令
- [x] 棋譜編碼後再解碼、重播，得到的局面與原局完全相同，包括預放的修改與移除（有測試）
- [x] 棋譜帶有格式版本號，解碼時會檢查（有測試）
