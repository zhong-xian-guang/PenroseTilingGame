# 01: 專案骨架與第一片拼塊

**What to build:** 打開網頁就看到一片 kite，可以平移、縮放盤面，可以從托盤點選 kite 或 dart；游標移動時，最近的候選放置會顯示預覽，滾輪只在合法方向之間循環，按左鍵放下。只有符合匹配規則、不重疊、且和鋪砌共用一整條邊的放置會出現。這張先建立整條路徑：規則引擎（以精確的 a + bφ 座標表示 P2 拼塊組與匹配規則，透過指令與查詢介面操作）、Canvas 盤面（支援 devicePixelRatio、顯示 Conway 弧線）、Svelte 5 托盤，以及 Vitest 引擎測試。開局暫時固定為一片 kite。規格見 `.scratch/penrose-mvp/spec.md`，介面框架見 ADR 0001。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 專案以 Vite + TypeScript + Svelte 5 建立，Vitest 可以執行
- [x] 規則引擎不依賴 DOM、Canvas 或 Svelte，對外只有指令與查詢介面
- [x] 頂點座標以 ℤ[φ] 係數表示，規則判定不使用浮點數比較
- [x] P2 拼塊組以資料描述：短邊 1、長邊 φ；kite 的角是 72°、72°、72°、144°，dart 的角是 36°、72°、36°、216°；匹配規則與 7 種頂點組態圖鑑
- [x] 查詢某位置的候選放置時，只回傳符合匹配規則、不重疊、與鋪砌共用一整條邊的放置（有測試）
- [x] 某位置的合法方向清單正確，而且只包含合法方向（有測試）
- [x] 盤面以 Canvas 2D 繪製，在高 DPI 螢幕上清晰，滑鼠拖曳可以平移、可以縮放
- [x] 拼塊上顯示 Conway 弧線
- [x] 滑鼠操作：點選托盤拼塊、顯示游標附近的候選放置預覽、滾輪循環合法方向、左鍵放下
