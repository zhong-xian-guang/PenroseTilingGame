# 05: 成長圓

**What to build:** 盤面上畫出一個淡淡的成長圓，只有圓內的邊界可以放新拼塊。圓心是鋪砌的質心，半徑 R = √(面積/π) + 餘量；面積增加時，圓跟著長大。圓內完全沒有任何候選放置時，也算死局。餘量是集中定義的可調常數。

**Blocked by:** 04 可見死局與遊戲結束

**Status:** resolved

- [x] 成長圓外的位置不會出現在候選放置中（有測試）
- [x] 面積增加時，半徑跟著增加（有測試）
- [x] 死局偵測只看成長圓內的凹處；圓內沒有任何候選放置時算死局（有測試）
- [x] 盤面上畫出成長圓
- [x] 餘量是集中定義、方便調整的常數；質心預設只用已確認鋪砌計算

## Comments

- 刻意偏離（程式碼審查後記錄）：「位在成長圓內」的判定對象是候選放置**所接的那條邊界邊**：只要那條邊有任何一點伸進圓內（線段到圓心的距離 ≤ R），黏在上面的拼塊就算候選，拼塊本身可以有一部分在圓外。理由：成長圓規定的是「哪段邊界開放」，以邊判定與死局判定（圓內的邊界邊）一致，也讓圓周附近的凹處不會因為拼塊稍微凸出圓外就無法填補。
- 程式碼審查後的修正：圓的判定改成只用 IEEE-754 精確運算（比較平方距離、常數寫成字面值），不再用 `Math.hypot`／`Math.sin`，見 `docs/adr/0002-growth-circle-ieee-exact-floats.md`。預放造成「圓內沒有任何候選放置」時，改成像預放造成的死局一樣標紅、遊戲繼續（可轉向或移除）；沒有預放時圓內沒有候選放置仍立即結束。放下新的一片時，先確認前一片、重算成長圓，再檢查已確認鋪砌的死局（有的話立即結束，標為 confirmed）。
