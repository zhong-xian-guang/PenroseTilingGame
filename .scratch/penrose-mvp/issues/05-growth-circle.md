# 05: 成長圓

**What to build:** 盤面上畫出一個淡淡的成長圓，只有圓內的邊界可以放新拼塊。圓心是鋪砌的質心，半徑 R = √(面積/π) + 餘量；面積增加時，圓跟著長大。圓內完全沒有任何候選放置時，也算死局。餘量是集中定義的可調常數。

**Blocked by:** 04 可見死局與遊戲結束

**Status:** ready-for-agent

- [ ] 成長圓外的位置不會出現在候選放置中（有測試）
- [ ] 面積增加時，半徑跟著增加（有測試）
- [ ] 死局偵測只看成長圓內的凹處；圓內沒有任何候選放置時算死局（有測試）
- [ ] 盤面上畫出成長圓
- [ ] 餘量是集中定義、方便調整的常數；質心預設只用已確認鋪砌計算
