# 15: 大鋪砌效能

**What to build:** 鋪砌長到數千片時，平移、縮放和放置仍然流暢。已確認鋪砌畫進離屏快取的圖塊，只重畫預放、預覽和疊加層；規則引擎用空間索引，每次放置只重算受影響區域的候選放置與死局判定。

**Blocked by:** 05 成長圓

**Status:** ready-for-agent

- [ ] 已確認鋪砌畫進離屏快取的圖塊，視窗外的部分不繪製
- [ ] 引擎以空間索引查詢鄰近拼塊；每次放置只重算局部，查詢結果與全盤重算一致（有測試）
- [ ] 在中階手機上，鋪砌 5000 片時平移與縮放維持接近 60fps（手動量測，記錄結果）
- [ ] 每次放置後，引擎的處理時間在中階手機上低於一幀
