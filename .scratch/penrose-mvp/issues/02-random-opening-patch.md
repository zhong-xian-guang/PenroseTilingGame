# 02: 隨機開局圖形

**What to build:** 每開一局都會從隨機抽出的開局圖形開始，它是 3 到 6 片相連、保證合法的 P2 鋪砌，不一定對稱；鏡頭自動置中並縮放到開局圖形，玩家可以隨時開新局。開局圖形由細分（deflation）產生的參考鋪砌，依種子切出。

**Blocked by:** 01 專案骨架與第一片拼塊

**Status:** resolved

- [x] 同一個種子產生的開局圖形完全相同（有測試）
- [x] 開局片數在 3 到 6 之間，而且彼此相連（有測試）
- [x] 開局圖形符合匹配規則，每個內部頂點都屬於 7 種頂點組態之一（有測試）
- [x] 開新局時鏡頭置中並縮放到開局圖形
